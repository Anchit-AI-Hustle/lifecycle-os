The SOP makes measurement depend on names: organic post URL → videoid → ad name → ad code → paid performance. An ad without the videoid still runs but cannot be joined to its organic performance, so that spend produces no learning. Every figure below is computed from the live warehouse names and the real dollars behind them. Full procedure: the SOP tab · SOP PDF. The nomenclature is live from Monday, so older names predate it — this is the measured baseline.
