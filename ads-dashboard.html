Naming compliance, live names scored against the standard

A naming standard is what makes measurement joinable: organic post URL → videoid → ad name → ad code → paid performance. An ad without the videoid still runs but cannot be joined to its organic performance, so that spend produces no learning. Every figure below is computed from the live warehouse names and the real spend behind them. The structural rules (banned characters, lowercase, videoid, syntax) apply to anyone. The permitted token values are your own vocabulary and are read from ADS_SOP_TOKENS; none are bundled, so with none configured that check simply does not run.
