# Landing page audit

Audit: `$ARGUMENTS`.

## Method
1. Fetch the page. Extract: headline, subhead, hero media, CTAs (text + position), proof elements (reviews, badges), offer, page speed signals (weight, blocking assets).
2. Score against the conversion stack: Clarity (5-second test: what is it, for whom, why now) -> Relevance (message match with the ad/source) -> Proof (specific, attributed) -> Friction (fields, choices, load) -> Urgency (honest only).
3. Rewrite: 3 headline options (benefit-led, feeling-led, proof-led), 2 CTA rewrites, above-the-fold layout order.
4. Every critique cites the exact current copy/element; every rewrite obeys brand voice ("sell happiness" — the emotional end-state leads, never the ingredient spec).

## Output
1) Scorecard (5 dimensions, 1-10, one-line reason each). 2) Top 5 fixes ranked by expected impact. 3) Rewrites block, copy-paste ready. 4) What NOT to change (working elements).

## Brand guardrails (always)
- Palette #6A33D8 / #D0473E / #111111 / #F7F5F2; Montserrat headlines + Instrument Sans body.
- BANNED: streetwear journey, transform, liquid lava, game-changer, LIMITED TIME (caps), hurry, don't miss out, last chance, while supplies last. No em/en dashes in output copy.
- Zero fabrication: never invent numbers, benchmarks, reviews, prices or URLs. Missing input -> ask for it or mark [DATA REQUIRED].
- Mega-prompt discipline: be clear, concise and highly specific; every claim quotes the exact figure or line it came from.
