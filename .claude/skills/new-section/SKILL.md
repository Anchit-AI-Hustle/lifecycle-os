# New section

Follow these steps to build a new section:
1. Read the Design section of `CLAUDE.md`.
2. Ask for the section's content if it has not been given.
3. Build the section as its own component file.
4. Check it at 390px, 768px and 1440px wide and fix any layout problems.
5. Check that spacing above and below matches the other sections.
6. Finish with a three-line summary: what was built, which file, and anything the user should review.
