What we compared, and what we carried forward

The full side-by-side of this build's logic and approach against the rest of the app is in the comparison doc. The learnings worth acting on are summarised here, with what happened to each.

Deterministic slot planning (stableIndex, no random)carried forward
The Friday planner rotated plays and products with a stable hash so the same inputs always produce the same plan. This pattern was already extended into the Plan Calendar asset picker and stays the standard for every generator.
Never clobber a built mailer (status guard on upsert)carried forward
Persistence only overwrites slots that are not yet built. This guard is the model the live lifecycle persistence follows so human-approved work is never lost on a re-plan.
Brand gate reuse (one sanitizer, not three copies)carried forward
The Friday mailer builder called the shared sanitizeBrand() / banned-phrase check rather than duplicating the list. The live app now routes all generated copy through that single gate, extended with the no-em-dash and no-founder-voice rules.
Higher token ceiling for full-mailer JSONcarried forward
Friday's builder truncated at a low token cap. The live builders raised the ceiling and added a JSON-repair safety net, so mailer generation no longer fails mid-object.
Cohort-native calendar, parallel to the RFM planby design
The Friday build kept the lifecycle calendar separate from the V1 RFM Plan Calendar rather than merging them. That separation held up and is preserved: the two are the Draft 1 / Draft 2 pair described in the Cohorts dashboard.
Headers and footers baked into email HTMLsuperseded live
The frozen emails carry their own header and footer. The live program strips these so the copy pastes cleanly into Klaviyo templates. The frozen versions keep the original full-document form on purpose, as the record of the first approach.

This archive exists so the first day's thinking stays legible and comparable. It is intentionally immutable. If you need to change how any of these features behave, edit the live version reachable from the main menu, not the frozen copy here.
