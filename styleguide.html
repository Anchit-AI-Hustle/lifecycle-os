Reusable 3D Style Guide

Isolated examples of the layered text, raised card, dimensional icon, and hover-depth patterns introduced in the July 2026 welcome-page treatment. Every live example uses opt-in classes from theme.css.

Layered 3D Text

Stacked text shadows create the extrusion, while a perspective transform lifts the accent word onto a separate visual plane.

hello KNICKGASM

<div class="vh-3d-stage">
  <h3 class="vh-layered-title">
    hello <span class="vh-layered-title-accent">KNICKGASM</span>
  </h3>
</div>

.vh-layered-title {
  transform: rotateX(-5deg) rotateY(1deg) translateZ(18px);
  text-shadow: 0 1px 0 #d9e5ef, 0 2px 0 #cbd8e4,
    0 3px 0 #bdccda, 0 4px 0 #afc0cf,
    0 9px 18px rgba(23,36,61,.16);
}

Hover Depth Interaction

Hover the card to combine lift, counter-rotation, scale, and deeper shadows. Reduced-motion preferences keep the card static.

Hover for depth

The resting geometry and hover geometry are both driven by CSS custom properties.

<article class="vh-raised-card vh-raised-card--peach
  vh-depth-interaction">
  ...
</article>

.vh-depth-interaction:hover {
  transform: translateY(-8px) rotateX(-3deg)
    rotateY(var(--vh-3d-hover-turn)) rotateZ(0) scale(1.025);
  box-shadow: 0 4px 0 rgba(23,36,61,.12),
    0 16px 0 -5px var(--vh-3d-depth),
    0 30px 42px rgba(49,65,96,.22);
}
