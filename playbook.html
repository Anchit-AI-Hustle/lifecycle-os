Reading the funnel

  • SAM is 22.4% of TAM. The D2C and premium/functional slice is where provenance and a real functional payload win, and where price competition matters least.
  • SOM is 22.2% of SAM. Obtainable share is gated by acquisition efficiency and retention, not by demand. The playbook prioritises the second order and the subscription anchor because that is where the SOM actually compounds.
  • Where the leverage sits. Moving day-180 retention up a few points expands realised SOM faster than raising ad spend, because functional buyers carry a materially higher lifetime value.

version: 2
market: US
currency: USD

# Lifecycle hooks that fire against Klaviyo events.
# Each trigger names the cohort it protects and the expected metric it moves.
triggers:
  - id: second-order-nudge
    protects: cohort-004
    fires_on: order_number == 1
    delay_days: 9
    channel: [email, sms]
    condition: replenishment_window_days <= 14
    action: send_flow("second-order-lace-up-guide")
    target_metric: repeat_purchase_rate

  - id: subscription-anchor
    protects: cohort-002
    fires_on: product_category == "coffee" && subscription == false
    delay_days: 3
    channel: [email]
    action: offer("subscribe-first-refill-rhythm")
    target_metric: subscription_attach_rate

  - id: aov-recovery
    protects: cohort-001
    fires_on: order_aov_usd < segment_median_aov
    delay_days: 0
    channel: [email]
    action: recommend_bundle("hero-plus-two-complementary")
    target_metric: average_order_value

  - id: winback-about-to-sleep
    protects: cohort-003
    fires_on: days_since_last_order between 45 and 75
    delay_days: 0
    channel: [email, sms]
    action: send_flow("winback-ritual-reset")
    target_metric: reactivation_rate

  - id: discount-discipline
    protects: all
    fires_on: discount_requested == true
    guard: cohort != "cohort-001"   # protect full-margin loyalists
    action: route_to("curious-switcher-offer-only")
    target_metric: contribution_margin

defaults:
  quiet_hours: "21:00-08:00"
  max_touches_per_week: 3
  suppress_if: unsubscribed || bounced

Core Knowledge Base

Ingredient Source Verification

How each functional claim is backed. The rule for copy: state the verified source and payload, never a medical claim.

Single-studio origin

Sneaker and coffee tied to a named studio and drop. Batch records carry studio, elevation, and pick date. This is the provenance the premium rests on.

Functional payload

Coffee Collection carries a stated adaptogen dose per serving. Copy names the ingredient and the ritual benefit in plain, non-medical language.

Certification chain

B-Corp and ethical-sourcing certifications sit as trust proof beside the origin story, referenced but never used as the lead hook.
