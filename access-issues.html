Governance · Access Issues

Shopify access & app audit

A strictly read-only audit of who can reach the US Shopify store and which apps are installed, run entirely in your browser. Load the Shopify user, role, group, and activity CSV exports plus your app register and business context. Nothing is uploaded, no Shopify tool is called, and no change can be made to the account. The tool aggregates the evidence, derives effective access, and produces findings and recommendations for a human to approve and implement.

🔒
Read-only by architecture, not by promise.

This feature has no Shopify write path: it runs client-side over evidence you provide, never authenticates to the store, never issues a GraphQL mutation, and never requests a write_* scope. Remediation stays outside this tool: it emits recommendations only. See the governing policy at the bottom of the page.

1 · Operating model

Choose how the evidence was collected. Model A is the default and gives the strongest no-change guarantee.
Model A, Offline audit (recommended)
An authorized administrator exports the CSVs and captures read-only app, billing, and login evidence. This tool reads that evidence and produces findings only. Claude never holds a live Shopify capability. This page implements Model A.
Model B, Controlled live read-only
Shopify CLI / official AI Toolkit with read_* scopes only, no --allow-mutations, allow-listed query files, query logging. Run externally; paste the resulting JSON here as evidence. This tool does not perform Model B connections itself.

2 · Evidence intake

All parsing happens locally in your browser. Column names are matched flexibly to the Shopify export headers.
Settings → Users → Export. One row per user-role-store; aggregated by user ID.
Settings → Users → Roles → Export. Each permission and app per role.
Plus orgs: Settings → Users → Groups → Export. Maps groups to roles and stores.
Settings → Users → Security → activity log (up to 6 months of access changes).
Settings → Apps. Columns like app, developer, owner, purpose, permissions, last_activity, plan, monthly_cost (per month), usage_cost (per month), external_billed (per YEAR), category.
Per-user recent sessions (date, ip, location, browser). Optional.
